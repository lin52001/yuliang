# 余量 Codex 本地插件

插件试验版：`0.1.0-beta.2`。配套应用：余量 `0.17.1` build `24`；最低兼容余量 `0.17.0` build `23`。

插件把额度查询和小伙伴操作接入 Codex。它包含本地 MCP 工具及使用技能，共用余量 App 的采集器、人物和窗口。订阅额度仍以约 60 秒为目标间隔读取，插件不会再启动另一套定时采集。

## 可以做什么

| 入口 | 功能 |
| --- | --- |
| `yuliang_status` | 查询额度窗口、剩余百分比、读取时间及状态；独立返回可用的 Codex 日 Token 与累计 Token 统计 |
| `yuliang_refresh` | 请求现有采集器刷新 Codex 或 Claude；请求被接受不代表官网已经返回新数据 |
| `yuliang_show_widget` | 显示本机余量卡片 |
| `yuliang_interact` | 让当前角色随机回应，或播放指定的通用及专属动作 |
| `yuliang_select_character` | 切换本机可用的小伙伴 |
| `yuliang_set_display` | 切换标准、紧凑或 Duo，调整明暗外观和中英日语言 |

人物依然使用本机余量的原生界面。插件没有向 Codex 的账号区域注入图标，也没有提供已验证的 Codex 内嵌人物面板。安装插件、安装桌面应用和获得官方插件目录上架是不同步骤；本版通过仓库市场供本地试用。

日常操作优先使用上表六个 MCP 工具。备用 CLI 在受限 Shell 中运行时，可能没有访问本机连接目录的权限，即使相同账号下的 App 与 MCP 工具都正常；这种拒绝访问不代表 App 缺失或目录损坏。

v0.17.1 App 改进带装饰的进度条，使用柔和高光、主题符号与珠点，并在相同 Duo 外框内放大圆环和人物。这些变化显示在本机卡片中，插件可继续切换布局和触发互动；插件升级本身不会改变旧 App 的视觉。详见 [v0.17.1 更新说明](https://github.com/lin52001/yuliang/blob/main/RELEASE-v0.17.1.md)。

## 安装条件

- macOS 14 或更新版本、Node.js 20 或更新版本。
- 已安装余量 `0.17.0` build `23` 或更新版本，并至少打开过一次。已有兼容版本无需重复下载或安装；此前 build `22` 没有本地插件连接入口，需要更新。
- 使用支持本地插件市场的 Codex 桌面客户端或 CLI。CLI 可添加市场和安装插件；人物窗口的实际使用需要 Mac 图形界面。
- Codex 额度需要本机官方 Codex CLI 已登录。Claude 使用余量自己的官网登录窗口；插件不会代填密码、导入外部浏览器 Cookie 或复制认证文件。

没有安装余量时，先按仓库 [README](../README.md) 安装或从源码构建。插件包本身不包含应用安装包或角色图集，也不会自动下载、安装任何后台软件。它依赖本机原生后台，并非安装插件后即可独立采集和显示人物的版本。

## 添加本仓库的插件

1. 将本仓库添加为插件市场，再安装余量：

   ```sh
   codex plugin marketplace add lin52001/yuliang --ref main
   codex plugin add yuliang@yuliang-local --json
   ```

2. 重启 Codex 桌面客户端，在插件目录核对「余量」已安装或启用。也可以在添加市场后，直接从插件目录选择本仓库市场并完成安装。
3. 在新聊天中调用余量插件。插件先连接已运行的余量，必要时再尝试启动已安装 App；启动请求失败后仍等待本次连接回应。它不会重复安装 Codex 或开启新的账号登录。

从源码测试时，在本仓库根目录执行 `codex plugin marketplace add .`，再执行同一条 `codex plugin add yuliang@yuliang-local --json`。不要同时重复添加同名的本地和远程市场；更新已有市场时按 CLI 提示处理。

若客户端的 `codex plugin --help` 没有 `marketplace` 子命令，请先查阅该客户端的插件支持情况。官方也支持由仓库根目录的 `.agents/plugins/marketplace.json` 发现本地市场；该文件只负责让插件可被发现，不代表插件已经启用。

官方说明：[插件打包与本地市场](https://developers.openai.com/plugins/build/plugins)、[仅桌面插件](https://developers.openai.com/plugins/deploy/desktop-only)。本仓库不是官方通用插件目录。

## 从早期插件更新

已安装余量 v0.17.0 build 23 或更新版本的用户，修复插件连接时无需重装 App。v0.17.1 build 24 的视觉改动需要另行更新 App，但不是 beta.2 的最低要求。

若通过 GitHub 远程市场安装，先更新市场快照，再安装插件：

```sh
codex plugin marketplace upgrade yuliang-local --json
codex plugin add yuliang@yuliang-local --json
```

仅重新执行 `plugin add` 可能继续使用旧市场快照。从本机路径添加的市场无需执行远程 `marketplace upgrade`；确认本机源码已更新后安装插件即可。完成后重启 Codex，在新聊天中使用，核对插件版本为 `0.1.0-beta.2`。本机的额度、角色和显示偏好由 App 保留。

beta.2 修复自动启动异常被误报为未安装的问题。它先等待运行中的 App 回应，再尝试通过系统启动；整个过程共用同一条请求，不会重复触发互动或额外刷新。

beta.2 也区分受限 Shell 拒绝本机连接的情形，返回 `bridge_permission_denied`，不再统一归为连接不可用。使用包含此修复的插件后，重启 Codex 并开启新聊天，以加载更新后的工具和技能说明。

## 在聊天中使用

安装后可直接对 Codex 说：

- 使用余量看看我当前的剩余额度、Token 用量和更新时间。
- 刷新一次 Codex 额度，告诉我是否已经读到新数据。
- 打开余量小组件，切换到紧凑模式和浅色外观。
- 让当前小伙伴表演一下自己的专属动作。
- 列出现在可用的角色，然后换成云朵精灵。
- 把余量界面切换到日语。

刷新是异步操作。工具会区分已接受、正在读取和读取失败，不会把旧读数标成刚刚成功读取。自动吃饼干只由较新的真实额度消耗触发；手动娱乐动作不修改额度或 Token。

## 数据与隐私

插件通过本机文件队列与余量通信，不开启 HTTP 端口，也不设置远程隧道或自有云服务。队列只接受有限的查询和界面操作，不接受任意命令、任意路径或脚本。

查询结果会作为工具结果提供给当前 Codex 聊天。结果包括允许的额度及用量摘要、角色和显示设置；不包括登录凭据、Cookie、密码、API 密钥、聊天正文、账号邮箱或组织标识。请不要在公开 Issue 中粘贴真实账号的工具输出。

额度和 Token 是两种口径。Codex Token 统计保持服务端统计日与原始读取时间，不等同于当前聊天的精确消耗或剩余可用 Token。Claude 未提供的字段保持未知，也不会借用 Codex 的统计。Claude 付费账号的真实额度读取仍待完整端到端验收。

连接请求及响应暂存在：

```text
~/Library/Application Support/YuliangStandalone/PluginBridge/
```

本地连接文件使用仅当前用户可读写的权限。调用结束后清理对应请求与响应；无有效新观察时，界面继续保留旧记录及其原始时间，不伪造余额和更新时间。

## 角色素材

插件 ZIP 自身不打包图片，使用本机 App 已有的角色资源。v0.17.1 公开 App 与源码提供七位角色的形象及动作，包括奶龙与持剑小猫，无需另配参考图集。若仍在使用较早的兼容 App，其可用形象以该 App 为准；更新插件不会给旧 App 安装图片。动作代码与美术素材分别管理，角色来源、署名与使用条件见 [ASSETS.md](../ASSETS.md)。代码 MIT 许可不覆盖第三方人物、原设定或产品标识，不代表官方授权或联名。

## 常见问题

**App 在运行，旧插件却报 `app_unavailable`。** 早期插件会把系统启动请求异常统一报成 App 不可用，即使 App 已经正确安装。请更新到 beta.2，保持现有余量运行，再在新聊天中重试；已安装 build `23` 或更新版本时无需重装 App。

**自动启动失败。** 这不等于 App 未安装。先手动打开已安装的余量并保持运行，再重试插件。beta.2 会先等现有 App 回应，系统启动失败后也继续等待同一请求；只有仍未收到回应时才报告相应连接问题。若从未安装过兼容 App，再按安装条件处理，插件不会自动下载 App。

**MCP 能用，备用 CLI 却提示 `bridge_permission_denied`。** 受限 Shell 的文件访问范围可能与 MCP 进程不同。先使用上述 MCP 工具；若当前对话没有相应工具而确需使用 CLI，只为该次余量 CLI 命令申请本机执行权限，再重试同一操作。保持连接目录 700、文件 600 的私有权限，无需放宽目录、整个用户目录或整个 Codex 的权限，也不需要重装正确版本的 App、读取或复制认证文件。早期插件可能将同一问题显示为 `bridge_unavailable`；更新插件后重启客户端，并在新聊天中使用。

**查询超时。** 确认余量没有退出、Mac 已解锁；先正常打开余量，再通过 MCP 工具重试。若备用 CLI 被受限 Shell 拦截，按上面的权限问题处理，不通过放宽目录权限或复制认证文件解决。

**刷新后数值没变。** 请求可能仍在执行，或上游尚未更新。再次查询时应一起查看额度和 Token 各自的成功时间、状态，不以窗口打开时间代替读取时间。

**没有 Codex 内的小人物图标。** 本试验版的入口是插件工具和技能，人物显示于余量自己的原生卡片。账号上方的固定位置和聊天内嵌人物界面尚未实现。

**怎样停用？** 在 Codex 插件目录停用余量可停止其工具入口。退出余量 App 会停止采集和人物自主互动；停用插件不会删除本机额度记录，也不会退出官方 Codex 账号。
